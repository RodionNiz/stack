## О проекте

Проект включает в себя стандартный стек (LIFO структуру данных), а так же 3 уровня защиты этого стека.

---

## Структура кода

```
OneginSort.cpp

├── struct stack_t          //содержит рабочую и отладочную (при режиме отладки) информацию о стеке
├── enum ErrorCodes         //содержит коды ошибок, которые могут быть выявлены при проверке
├── ErrorCodes StackCtor    //создает стек заданой длины не равной 0 
├── int StackDestroy        //уничтожает переданый стек
├── ErrorCodes StackPush    //помещает в стек переданый элемент
├── ErrorCodes StackPop     //возвращает из стека последний элемент
├── ErrorCodes PrintStack   //печатает данные хранящиеся в стеке
├── ErrorCodes StkCpcUp     //при необходимости увеличивает размер стека
├── ErrorCodes StkCpcDown   //при необходимости уменьшает размер стека
├── size_t StackOk          //осуществляет проверки состояния стека (в режиме отладки)
├── void StackDump          //печатает в файл информацию о ошибке и состояние стека
├── int CheckCanary         //при включенной канареечной защите проверяет канарейку
├── size_t DJB2_HashCount   //расчитывает хэш данных в стеке
├── size_t DJB2_HashStruct  //расчитывает хэш структуры
└── void ClearMem           //Очищает использованную динамическую память.
```

## Форматы данных

Для вызова каждой функции можно использовать соответствующий ей макрос - название функции с припиской Call

>Например, StackCtorCall(stk, 2)

В функцию Push необходимо передавать название стека и элемент, который нужно записать в стек

В функцию Pop необходимо передавать название стека и имя переменной, в которую будет записано извлеченное значение

## Виды защиты

Программа способна осуществлять 3 уровня проверок правильности работы стека - базовый верификатор, канареечная защита и защита хешированием. Для включения режима верификатора необходимо прописать define ON_DBG, для последующего включения канаречной защиты или защиты хешированием необходимо сделать define ON_CANARY define и/или ON_HASH соответственно.

Канареечная защита обеспечивает наличие канареек для структуры стека и значений, хранящихся в нем

Защита хешированием обеспечивает наличие отдельнных хешей для структуры стека и данных в нем (хеш функция - DJB2)
